# Azure Bicep Builder — Next.js Landing Website

Official product landing page and download portal for **Azure Bicep Builder (ABB)**, built with Next.js 15 (App Router).

## Getting Started

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploying to Vercel

1. Import this repository in your Vercel Dashboard.
2. In Project Settings, set **Root Directory** to `website`.
3. Framework Preset will auto-detect **Next.js**.
4. Click **Deploy**.

## Downloads Directory
The desktop application binaries are hosted in `public/downloads/`:
- `Azure-Bicep-Builder-macOS.dmg` (Apple Silicon & Intel DMG)
- `Azure-Bicep-Builder-macOS.zip` (Portable ZIP archive)
